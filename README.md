## 🔨 Featured projects

**[PhilosophOS](https://github.com/AssvinEswarathas/philosophos)**: Multi-agent AI debate engine. Five philosopher agents (Nietzsche, Kant, Sartre, Camus, Aurelius) argue live over WebSockets, while a graph extractor maps every claim into a supports/challenges argument graph in Neo4j, rendered with D3.

**[Letterboxd Taste Graph](https://github.com/AssvinEswarathas/letterboxd-taste-graph)**: Content-based film recommender built on my own Letterboxd history. An ETL pipeline enriches ratings with TMDB metadata into Postgres and Neo4j. It hits 4x recall@10 over a popularity baseline (28.6% vs 7.1%), served through a FastAPI backend with Redis caching (6.46s → 3ms).
